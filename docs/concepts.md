# Основные концепции

В этом разделе мы рассмотрим ключевые концепции RWRTW, которые лежат в основе работы фреймворка.

## MVVM архитектура

RWRTW реализует паттерн Model-View-ViewModel (MVVM) с автоматической синхронизацией модели, промежуточных данных и представления. Это позволяет разработчикам сосредоточиться на бизнес-логике, а не на ручной синхронизации данных между различными частями приложения.

## Сигнальная реактивность

Основой RWRTW является система сигнальной реактивности, основанная на сигналах (signals). В отличие от традиционных систем реактивности, RWRTW использует fine-grained реактивность, где каждая зависимость отслеживается отдельно.

### Состояние

Состояние в RWRTW создаётся с помощью функции `state`:

```ts
import { state } from "rwrtw"

const count = state(0)
```

Функция `state` возвращает объект, который имеет методы:
- `get()` - получение значения состояния
- `set(value)` - установка нового значения состояния

### Вычисляемые значения

Вычисляемые значения создаются с помощью функции `computed`:

```ts
import { state, computed } from "rwrtw"

const count = state(0)
const doubleCount = computed(() => count.get() * 2)
```

Вычисляемые значения автоматически пересчитываются при изменении зависимостей.

## Динамические узлы

RWRTW использует концепцию динамических узлов для представления компонентов. Эти узлы могут содержать как статический, так и динамический контент.

### Корневые узлы

Корневые узлы создаются с помощью функции `createRootDynamicNodeAt`:

```ts
import { createRootDynamicNodeAt, placeAtBeginningOf } from "rwrtw"

const root = createRootDynamicNodeAt(
  placeAtBeginningOf(document.body),
  fragment
)
```

### Динамические фрагменты

Фрагменты создаются с помощью функции `fr`:

```ts
import { fr } from "rwrtw"

const fragment = fr(<MyComponent />)
```

## JSX Runtime

RWRTW предоставляет JSX runtime для удобного создания пользовательского интерфейса. JSX компоненты транслируются в вызовы функций, которые создают динамические узлы.

### События

События обрабатываются через специальный синтаксис `on:`:

```tsx
<button on:click={handleClick}>
  Нажми меня
</button>
```

### Условный рендеринг

Условный рендеринг реализуется через обычные JS выражения:

```tsx
{showContent && <div>Содержимое</div>}
```

### Динамические списки

Для создания динамических списков используется функция `createListAt`:

```ts
import { createListAt } from "rwrtw"

const items = state([1, 2, 3])
createListAt(container, items, (item) => <div>{item}</div>)
```

## DOM API

RWRTW работает напрямую с DOM API, что обеспечивает высокую производительность и минимизирует количество абстракций. Все операции с DOM выполняются через специальные функции, которые обеспечивают безопасность и эффективность.

## Оптимизации

### Fine-grained реактивность

RWRTW использует fine-grained реактивность для точного отслеживания зависимостей, что позволяет избежать ненужных перерисовок.

### Tree-shaking дружелюбный код

Код разбит на модули, что делает его дружелюбным к tree-shaking. Все экспорты статически разрешаемы.

### Минимизация памяти

Фреймворк минимизирует использование памяти, избегая создания лишних объектов, массивов и замыканий без необходимости.

## Принципы разработки

RWRTW следует ряду принципов, которые обеспечивают высокое качество кода:

1. **Отсутствие сторонних зависимостей** - только vanilla JS и API браузера
2. **Прозрачность работы** - знакомые разработчикам HTML, CSS, DOM API, event handling, WebComponents
3. **Минимальный размер бандла** - важнее, чем скорость работы
4. **Использование современного JavaScript** - не учитываем устаревшие подходы
5. **Developer Experience** - приоритет разработчикам
6. **Строгая типизация** - все код должен быть максимально строго типизирован
7. **Код дружественный для минификации** - избегаем строковых литералов как ключей объектов
8. **Tree-shaking дружелюбный код** - статически разрешаемые экспорты, минимальные зависимости

Эти концепции обеспечивают высокую производительность и лёгкость в использовании RWRTW.
