# Добро пожаловать в RWRTW

RWRTW — это Web UI-фреймворк с "fine-grained" реактивностью, основанный на сигналах, декларативном синтаксисе на основе JSX и оптимизирующим компилятором.

## Что такое RWRTW?

RWRTW — это реализация паттерна MVVM с автоматической синхронизацией модели, промежуточных данных и представления. Фреймворк позволяет создавать интерактивные пользовательские интерфейсы с высокой производительностью и минимальным размером бандла.

## Основные особенности

- **Fine-grained реактивность**: Система сигналов обеспечивает точное отслеживание зависимостей
- **Декларативный синтаксис**: Использование JSX для описания пользовательского интерфейса
- **Оптимизирующий компилятор**: Преобразование JSX в оптимизированные шаблоны на этапе сборки
- **Минимальный размер бандла**: Оптимизации для уменьшения размера финальной сборки
- **Строгая типизация**: Полная поддержка TypeScript
- **Нативные возможности браузера**: Минимальное количество абстракций, работа с DOM API напрямую

## Структура фреймворка

RWRTW состоит из следующих слоёв, каждый из которых может использоваться непосредственно самостоятельно:

1. **Core** - набор библиотек на TypeScript:
   - реализация слоя абстракции манипуляций с DOM
   - реализация сигнальной реактивности
   - простой DSL из типизированных функций, чтобы связывать всё вместе

2. **Runtime TSX** - реализация JSX-runtime, использующая примитивы из Core

3. **Template TSX** - трансформер JSX на этапе сборки, превращающий фрагменты JSX в оптимизированные шаблоны

4. **Declarative TSX** - компилятор декларативного кода на TypeScript, реализация компилируемой реактивности

## Цели проекта

- Разработка высокопроизводительного UI-фреймворка с минимальным размером бандла
- Поддержка современных возможностей JavaScript и нативных API браузера
- Обеспечение отличного Developer Experience
- Строгая типизация и отсутствие сторонних зависимостей
- Прозрачность работы для разработчиков, знакомых с HTML, CSS, DOM API

## Статус проекта

Проект находится на стадии экспериментов и "proof of concept". Не рекомендуется к использованию в продакшене, но предлагается к рассмотрению для изучения концепций и подходов.
